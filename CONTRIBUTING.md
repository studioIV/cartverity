# Contributing

Keep cartridge access read-only and every script write limited to SD logs. Do not add permission unlocks, repair commands, save writes, installations, or automatic conversion of observations into trusted references.

Run the checks in the README. For script changes, add scenarios that exercise the changed outcome or failure behavior. Update documentation and log version when changing their public contract. Keep the script ASCII and LF-terminated for straightforward GodMode9 parsing.

Hardware reports are especially useful. Include the exact GodMode9 version, console family, cartridge type/region/revision if known, outcome, and a redacted log. Distinguish a separately dumped comparison from a trusted reference with provenance. Do not attach game ROMs, copyrighted databases, saves, keys, or console serials.

Keep compatibility and testing claims proportional to evidence. The simulator cannot certify hardware behavior.
